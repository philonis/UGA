# UGA 游戏评分网站

游戏全生命周期追踪评价平台

## 🌐 在线预览

https://gao-lab.github.io/UGA/

## 🚀 本地开发

```bash
# 前端
cd frontend/public
python3 -m http.server 8080

# 后端
cd backend
npm install
npm run dev
```

## 📄 页面

- 首页：`/index-pro.html`
- 发售表：`/release.html`
- UGA 大奖：`/uga-awards.html`

## 🛠️ 技术栈

- 前端：HTML + TailwindCSS
- 后端：Node.js + Express
- 数据库：JSON（开发）/ PostgreSQL（生产）
