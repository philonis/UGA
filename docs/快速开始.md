# UGA 项目 - 快速开始指南

## 环境要求

- Node.js >= 18.0
- npm >= 9.0

## 安装步骤

### 1. 安装后端依赖

```bash
cd /Users/qihoo/UGA/backend
cp .env.example .env
npm install
```

### 2. 安装前端依赖

```bash
cd /Users/qihoo/UGA/frontend
npm install
```

### 3. 启动开发服务器

**终端 1 - 后端：**
```bash
cd /Users/qihoo/UGA/backend
npm run dev
# 启动在 http://localhost:3001
```

**终端 2 - 前端：**
```bash
cd /Users/qihoo/UGA/frontend
npm run dev
# 启动在 http://localhost:3000
```

## API 端点

| 端点 | 方法 | 描述 |
|------|------|------|
| `/api` | GET | API 状态 |
| `/api/games` | GET | 游戏列表 |
| `/api/games/:id` | GET | 游戏详情 |
| `/api/releases` | GET | 发售表 |
| `/api/uga-awards` | GET | UGA 大奖信息 |
| `/api/scrape/steam` | POST | 抓取 Steam 数据 |

## 常见问题

**Q: 端口被占用？**
A: 修改 `backend/.env` 中的 `PORT` 变量

**Q: 前端无法连接后端？**
A: 确保后端已启动，检查 CORS 配置
