# UGA 游戏评分网站 - 需求文档

## 项目概述

**目标**：建立独一无二、对游戏进行全生命周期追踪的评价体系，形成"网站版行业白皮书"数据库

**核心价值**：
- 游戏全生命周期追踪（发售前→发售时→发售后）
- 多维度评分聚合（中国媒体/KOL/海外媒体/玩家）
- UGA 颁奖典礼投票系统

---

## 一期需求

### 1. 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 评测评分 | 中国媒体、KOL 评分及评测 | P0 |
| 海外评分聚合 | 聚合 Metacritic 等海外评分 | P0 |
| 玩家评分 | 预留接口（二期实现） | P1 |
| Steam 数据抓取 | 自动抓取游戏基础信息 | P0 |

### 2. 页面结构

- [ ] UGA 颁奖典礼 Banner（投票/回顾/得奖标识）
